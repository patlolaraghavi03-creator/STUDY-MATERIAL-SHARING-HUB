# Study Material Sharing Hub

A modern, responsive full-stack web application designed for college students and beginners to easily share, discover, search, and manage study materials, lecture notes, cheat sheets, and assignments.

---

## 1. Project Overview & Technology Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Responsive modern UI with cards, search, filters, and modals).
* **Backend:** Node.js, Express.js REST API.[cite: 2]
* **Database & Auth:** Supabase PostgreSQL with Row Level Security (RLS).[cite: 2]
* **API Communication:** Fetch API.[cite: 2]
